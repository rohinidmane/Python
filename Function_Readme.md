# 🧠 Python: Functions

## 📌 Overview

This project covers Python User-Defined Functions with practical coding examples to understand reusable functions, arguments, return values, generators, and recursion.

## ⚙️ Functions

Demonstrates how to create and use functions, handle different types of arguments, return values, and solve problems using generators and recursion.

Topics Covered:

- User-Defined Functions
- Function Calling and Arguments
- Default Parameters
- Return Statement
- Conditional Statements
- List Filtering (Even Numbers)
- Generators using `yield`
- Recursive Functions (Factorial and Sum of Natural Numbers)

## 🛠️ Technologies

- Python
- Jupyter Notebook
- Google Colab

## 🚀 Key Learning

Learned to create reusable functions, pass arguments, return values, filter lists, generate sequences using `yield`, and solve problems using recursion.
