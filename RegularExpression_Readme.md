# 🧠 Python: Regular Expressions (RegEx)

## 📌 Overview
This project covers **Regular Expressions (RegEx)** in Python using the `re` module to search, find, split, match, and replace patterns in text.

## 🎯 Learning Objectives
- Understand the basics of regular expressions.
- Learn to search and extract specific text patterns.
- Identify and extract phone numbers using RegEx.
- Apply pattern matching using special symbols and characters.
- Replace and split text using regular expressions.

## 🔷 Topics Covered
- **re.search():** Searching for a specific pattern in a string.
- **re.findall():** Finding all occurrences of a pattern.
- **re.split():** Splitting strings based on a regular expression.
- **re.sub():** Replacing matched patterns with new text.
- **re.match():** Checking for a pattern at the beginning of a string.
- **Pattern Matching:** Using digits, characters, word boundaries, and special symbols.
- **Capture Groups:** Extracting specific parts of matched text.
- **Flags and Lookahead:** Using `re.IGNORECASE` and lookahead expressions.

## 💻 Usage Examples
- Extracting month and year from a sentence.
- Finding specific words in text.
- Extracting phone numbers using regular expressions.
- Finding overlapping patterns using lookahead.
- Splitting text using spaces and special characters.
- Replacing text with case-sensitive and case-insensitive options.
