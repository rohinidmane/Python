# 🧠 Python Basics: For Loops & Functions

## 📌 Overview
This project covers two important Python concepts: **For Loops** and **Functions**, with practical coding examples.

## 🔁 For Loop
Explores different looping techniques to repeat tasks and iterate through data.

**Topics Covered:**
- List and String Iteration
- String Slicing
- `range()` Function
- Multiple Variable Assignment
- Tuple Unpacking
- `enumerate()` and `zip()`
- Nested For Loops
- Multiplication Table

## ⚙️ Functions
Demonstrates how to create reusable functions and work with different types of arguments and return values.

**Topics Covered:**
- User-Defined Functions
- Function Calling and Arguments
- Default Parameters
- Return Statement
- Conditional Statements
- List Filtering (Even Numbers)
- Generators using `yield`
- Recursive Functions (Factorial and Sum of Natural Numbers)

## 🛠️ Technologies
- Python
- Jupyter Notebook
- Google Colab

## 🚀 Key Learning
Learned how to use loops for iteration, create reusable functions, filter data, work with generators, and understand recursion.
