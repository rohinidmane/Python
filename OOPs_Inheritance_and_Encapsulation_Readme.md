# 🧠 Python: Inheritance & Encapsulation

## 📌 Overview

This project covers two important **OOP concepts: Inheritance and Encapsulation** in Python through practical coding examples.

## 🎯 Learning Objectives

- Understand inheritance and its importance in code reusability.
- Learn how parent and child classes work.
- Understand method overriding and `super()`.
- Identify public, protected, and private variables.
- Learn to access and modify private attributes using getter and setter methods.

## 🔷 Topics Covered

- **Method Overriding:** Redefining parent class methods in child classes.
- **Inheritance:** Reusing parent class properties and methods using `super()`.
- **Encapsulation:** Understanding public, protected, and private variables.
- **Getter and Setter Methods:** Accessing and modifying private attributes.
- **Data Hiding:** Protecting sensitive information using private variables.

## 💻 Usage Examples

- **Animal and Dog:** Demonstrating method overriding.
- **Vehicle and Car:** Implementing inheritance using parent and child classes.
- **Demo Class:** Understanding public, protected, and private access.
- **Person Class:** Managing private attributes using getter and setter methods.
- **Bank Account:** Managing deposits, withdrawals, and account balance.
- **Student Task (Day 17):** Creating parent and child student classes using inheritance and encapsulation.

## 🛠️ Technologies

## 🚀 Key Learning

Learned how inheritance promotes code reusability and how encapsulation protects data using access control and getter/setter methods.
