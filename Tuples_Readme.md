# 🧠 Python: Tuples

## 📌 Overview
This project covers **Tuples** in Python with practical examples to understand tuple creation, accessing elements, slicing, nesting, and tuple operations.

## 🎯 Learning Objectives
- Understand tuple creation and its properties.
- Learn positive and negative indexing.
- Access tuple elements using slicing.
- Understand nested tuples.
- Learn tuple methods and operations.
- Convert tuples into lists and vice versa.

## 🔷 Topics Covered
- Creating Empty and Non-Empty Tuples
- Accessing Tuple Elements
- Positive and Negative Indexing
- Tuple Slicing
- Nested Tuples
- Tuple Immutability
- Deleting Tuples
- Type Conversion (Tuple to List and List to Tuple)
- Tuple Methods: `count()` and `index()`
- Tuple Operations
- Using `zip()` with Lists of Tuples

## 💻 Usage Examples
- Creating tuples with different data types.
- Accessing elements using positive and negative indexes.
- Reversing and slicing tuples.
- Accessing elements from nested tuples.
- Modifying tuple data through list conversion.
- Combining names and ages using `zip()`.

## 🛠️ Technologies
- Python
- Jupyter Notebook
- Google Colab

## 🚀 Key Learning
Learned how to create, access, and manipulate tuples, understand their immutable nature, use tuple methods, perform slicing, and work with tuple operations in Python.
