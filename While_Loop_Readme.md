# 🧠 Python: While Loops

## 📌 Overview
This project covers **While Loops** in Python with practical examples of repeated execution, user input, and nested loops.

## 🎯 Learning Objectives
- Understand the working of while loops.
- Learn how to control loop execution using conditions.
- Perform calculations using loops.
- Understand nested while loops.

## 🔷 Topics Covered
- While Loop Basics
- Loop Conditions
- Increment and Decrement (`i += 1`)
- User Input with While Loop
- Sum of Numbers using While Loop
- Loop Termination using a Sentinel Value (`0`)
- Nested While Loops

## 💻 Usage Examples
- Printing numbers using a while loop.
- Calculating the sum of user-entered numbers until 0 is entered.
- Using nested while loops to display combinations of `i` and `j`.

## 🛠️ Technologies
- Python
- Jupyter Notebook
- Google Colab

## 🚀 Key Learning
Learned how to use while loops for repeated execution, handle user input, perform calculations, and implement nested loops in Python.
