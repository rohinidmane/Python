# 🧠 Python: List

## 📌 Overview

This project covers Python Lists with practical coding examples to understand list creation, accessing elements, slicing, adding, and removing elements.

## 📋 Lists

Explores different list operations and techniques to store, access, and modify data.

Topics Covered:

- Creating Empty and Non-Empty Lists
- Creating Mixed Data Type Lists
- Nested Lists (List Inside a List)
- Accessing List Elements
- Positive and Negative Indexing
- `index()` Method
- List Slicing
- Adding Elements using `append()`, `insert()`, and `extend()`
- Removing Elements using `remove()`

## 🛠️ Technologies

- Python
- Jupyter Notebook
- Google Colab

## 🚀 Key Learning

Learned how to create and access lists, work with indexing and slicing, handle nested lists, and perform different operations to add and remove elements.
