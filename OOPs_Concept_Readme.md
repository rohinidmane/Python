# 🧠 Python: Object-Oriented Programming (OOP)

## 📌 Overview

This project covers important **Object-Oriented Programming (OOP)** concepts in Python with practical examples of classes, objects, inheritance, polymorphism, encapsulation, and abstraction.

## 🔷 Topics Covered

- **Classes and Objects:** Creating classes, constructors, attributes, and methods.
- **Polymorphism:** Using the same function or method with different objects.
- **Inheritance:** Reusing parent class properties and methods in child classes.
- **Encapsulation:** Protecting data using private attributes and controlled access.
- **Abstraction:** Hiding implementation details using abstract classes and methods.

## 💻 Usage Examples

- **Student Class:** Creating student objects and displaying their details.
- **Shapes:** Calculating areas of Circle, Rectangle, and Square using polymorphism.
- **Vehicle and Car:** Demonstrating inheritance using a vehicle class.
- **Bank Account:** Managing deposits, withdrawals, and balance using encapsulation.
- **Animal and ATM:** Implementing abstraction using abstract classes.
